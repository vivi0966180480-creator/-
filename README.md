# 🎲 班級抽籤與分組

專為老師打造的課堂互動工具，支援隨機抽籤與自動分組，讓點名和分組變得有趣又高效。

## ✨ 功能特色

### 📋 名單管理
- 上傳 CSV 檔案或直接貼上學生姓名
- 偵測重複姓名並提供一鍵移除
- 內建模擬名單，快速體驗所有功能

### 🎰 隨機抽籤
- 老虎機風格的滾動動畫
- 多種音效主題與音量控制
- 可設定允許或不允許重複抽取
- 完整的抽取歷史紀錄

### 👥 自動分組
- 自訂每組人數，一鍵隨機分組
- 餘數分配策略設定
- 視覺化分組結果呈現
- 支援匯出分組結果為 CSV

## 🛠️ 技術架構

- **React 19** + **TypeScript**
- **Vite** 開發與建構
- **Tailwind CSS** 樣式框架
- **Motion** 動畫效果
- **Lucide React** 圖示
- **Web Audio API** 音效引擎

## 🚀 開發

```bash
# 安裝依賴
npm install

# 啟動開發伺服器
npm run dev

# 建構生產版本
npm run build
```

## 📦 部署

本專案可直接部署至 Vercel、Netlify 等靜態網站服務。Vercel 會自動偵測 Vite 框架並完成建構。
